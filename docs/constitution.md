# constitution.md — 工程宪法

> 这份文件是什么：本仓库不可协商的工程规则，每条附违反后果。条款全部可执行、可检查，没有"尽量""应该"。
> 什么时候该读：每个开发 session 开始前（AI 助手由 AGENTS.md 引导至此）；review 任何 PR 时逐条对照。
> 日期：2026-09-12

---

## 第 1 条：新代码必须带测试

任何新增或修改的行为代码，同一个提交里必须有覆盖它的测试。

**违反后果**：未测试代码合并即产生"理解债"——能跑但没人敢改，回归不可见，后续所有改动成本翻倍。

## 第 2 条：先移契约测试，再移实现

移植 Orca 编排协议时，先把它的 orchestration 契约测试改造成我们的验收测试（红色），再写实现让测试转绿。测试通过 = 行为等价，成熟度是客观事实，不靠感觉。

**违反后果**：先写实现等于让 AI 从零设计协议——设计决策现编，犯错空间比移植大一个数量级，且无法证明与原版行为等价。

## 第 3 条：编排逻辑只许放 `packages/orchestrator/`

所有编排代码（DAG、路由、worker 契约、聚合评审）住在这个独立包里，只通过适配层接触 AionUi 核心。**不许改 AionUi 核心目录**（`packages/desktop`、`packages/web-cli`、`packages/web-host`、`packages/shared-scripts` 的既有文件）。顺架构缝长，不切开它的肉。

**违反后果**：侵入核心的每一行都是上游同步时的冲突面；三个月后要麽放弃同步变成孤版，要麽一半时间在 rebase。

## 第 4 条：上游策略——锁版本、选择性搬、永不盲目 rebase

锁定 AionUi v2.2.2 开发。每月看一次上游 changelog，按需 cherry-pick 单个修复。**禁止 `git rebase` / `git merge` 上游 main。**

**违反后果**：上游快速迭代，盲目同步 = 每次同步都是一次未知规模的冲突地狱，开发节奏被上游绑架。

## 第 5 条：Spec-driven 流程

每个功能的固定流水线：`spec → plan → 多模型 fan-out 实现 → 交叉评审 → 合并`。

- 任务拆到"可独立 review、可独立测试"的粒度（单次改动限制影响半径）；
- 先审 spec 再审代码——写码前发现理解偏差成本最低；
- 代码不对就改 spec 重新生成，**迭代 spec 而非在烂代码上打补丁**。

**违反后果**：AI 一次改 20 个文件必然失控（业界数据：AI PR 平均 2.6 倍大、合并率不到一半）；跳过 spec 审查，偏差会在代码里才暴露，返工成本最高。

## 第 6 条：移植 > 从零写

设计决策已被 Orca / hermes 做完并验证过的事，AI 只做"映射"（消息类型对应、状态机对应、存储模型对应），不重新设计。动手前先查 docs/research.md 和 modes-inventory 里有没有现成蓝本。

**违反后果**：从零写 = 放弃继承来的成熟度，去赌 AI 的临场设计能力。

## 第 7 条：JSONL 埋点从第一天存在

每次任务执行必须落一条 JSONL 记录，字段：`task_type / model / provider / outcome / score / cost / latency / verifier`。存储 append-only，定期蒸馏成路由偏好（参考 hermes learning 晋升管线模式：提案 → 审批 → 晋升 → 可回滚）。

**违反后果**：没有效果数据，路由策略永远靠猜，"编排智能"退化成玄学；这份数据是长期资产，缺一天少一天。

## 第 8 条：交叉评审用自家 MOA 思路

实现用一个模型，评审用另外两个模型，结论一致才算数；不一致触发第三轮。

**违反后果**：单次 LLM 评审不稳定是已证实的痛点，单模型自审 = 没有评审。省下的 review 时间会变成理解债连本带利收回来。

## 第 9 条：Scope 冷静期

任何新想法（包括用户的）先写进 backlog，冷静三天后才允许排期。

**违反后果**：scope 失控是个人开发者的头号死法——"顺便把 XX 也做了"会让旗舰永远到不了验证日。

## 第 10 条：前缀缓存纪律（继承自 hermes）

会话中途不改 system prompt、不换工具集、不重载记忆。guidance 注入一律用追加式，放在消息列表末尾。

**违反后果**：KV 前缀缓存失效，每次注入全量重算——延迟和成本同时爆炸，且劣化无声无息。

## 第 11 条：端点层只接"会说 ACP 或有官方非交互模式的 CLI"

不为裸 API 自建 agent loop。接裸端点意味着自己实现工具调用循环、审批、会话恢复——那是 substrate，该买不该造。

**违反后果**：工程量膨胀一个数量级，且造出来的 loop 天然不如各厂官方 CLI 成熟，维护负担永久跟着我们。
